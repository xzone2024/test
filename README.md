# 漫剧资产管理工具（原型）

## 新增能力（本次更新）

- 新增 **故事大纲模块**：可从资产库拉取角色，排列顺序并编写剧情草案（头脑风暴）。
- 新增 **通用分镜模块**：保存分镜文字提示词，支持上传预览视频与提示词复制。
- 资产分类新增 **镜头调度**。
- 新建资产新增 **提示词（选填）** 字段：若填写，资产卡片会出现“复制提示词”按钮。

## 资产录入（最小化）

- 名称（必填）
- 标签（可选）
- 图片（必填）
- 提示词（选填）

其余字段自动处理：UID 自动生成、缩略图自动生成。

## 启动

```bash
npm install
npm run dev
```

打开：`http://localhost:5173`

## 说明

- 点击详情大图会尝试打开图片所在文件夹（受浏览器安全策略限制，属于 best effort）。
