# 漫剧资产管理工具（原型）

基于 **React + TypeScript + Tailwind CSS + motion + lucide-react** 的多维度资产分类库原型。

## 功能概览

- 分类导航（职业、怪物、武器、装备/道具、技能特效）
- AI Prototype 与 Final Render 双图对比
- Positive / Negative Prompt 记录与一键复制
- 资产 CRUD（新增、编辑、删除）
- 名称/提示词搜索与动态标签筛选
- 响应式布局与动效过渡

## 1) 安装与启动

```bash
npm install
npm run dev
```

浏览器访问：

- `http://localhost:5173`

生产构建：

```bash
npm run build
npm run preview
```

## 2) 页面怎么用（按工作流）

### A. 切换资产分类

- 左侧导航点击分类（职业 / 怪物 / 武器 / 装备/道具 / 技能特效），主区域会切换到该分类资产列表。

### B. 搜索与筛选

- 在顶部搜索框输入关键词，可匹配：
  - 资产名称
  - Positive Prompt
  - Negative Prompt
- 点击标签按钮进行过滤；`全部` 表示不过滤标签。

### C. 新增资产

右侧「新增资产」表单中填写：

- 名称
- UID
- 版本号
- 分类
- 标签（用英文逗号分隔，如：`科幻, 远程, 紫色`）
- Positive Prompt
- Negative Prompt
- 上传 AI 原型图 / 最终效果图

点击「保存资产」后会自动加入列表。

### D. 编辑与删除

- 鼠标悬停在资产卡片右上角，会出现：
  - ✏️ 编辑
  - 🗑 删除
- 点击编辑会把数据回填到右侧表单，修改后再次点击「保存资产」即可更新。

### E. 查看详情与复制提示词

- 点击任意资产卡片，右侧会显示完整详情：
  - UID、版本、分类
  - AI Prototype 与 Final Render 对比图
  - Positive / Negative Prompt
- 点击「一键复制」可复制对应提示词到剪贴板。

## 4) 常见问题

### Q1: `npm install` 失败（403 / 网络错误）怎么办？

通常是当前环境无法访问 npm registry。请在可联网环境中重试，或配置可用 npm 源后再执行。

### Q2: 上传图片后是否会永久保存？

当前是前端原型，数据保存在浏览器运行时内存中，刷新页面会丢失。后续可接入后端持久化。

### Q3: 可以多人协作吗？

当前版本不含登录与权限系统。后续可扩展用户体系与协作流程。
